# 点界 Android

最低 Android 9（API 28），target SDK 35；当前 0.2.13（16）。名称为「点界」，使用 iOS 同一份 AppIcon 原图。所有页面统一黑底、深灰卡片与靛蓝操作色。录制控件对齐 iOS CaptureView 的 112 / 88 dp 圆钮、取景框 / 停止方块、录制放大动画、轻点和按住松手保存。

## 当前能力

- 五个主入口：记录、想法、宇宙、图片、我的。
- “我的”页内检查应用更新：读取 VPS 最新版本，显示更新说明与下载进度，校验 APK 后打开 Android 系统安装确认；无需登录，隐私版同样可用。
- 语音 / 文本切换、文字草稿、AAC / M4A 原音落盘，单条最长 10 分钟；离开前台结束并尝试保存。
- 可选 Camera2 预览与录音期间采样（每 1.2 秒一张，最多 12 张），结束后均匀选出最多 5 张供勾选保留；相册、系统拍照、方形裁切与涂鸦。
- 原音播放器、进度拖动、多个转写候选、独立的人工修正。重新转写不覆盖人工修正。
- 真正的中文离线转写：Vosk Android 0.3.75 + `vosk-model-small-cn-0.22`。模型约 42 MB，在“我的”页按需下载；SHA-256 校验后安装，支持暂停与断点继续，安装后识别不调用网络或系统在线识别。模型是单独的中文语音引擎，不是本地生成式大模型。
- 图片文字识别与图片理解均使用点界云端视觉模型；登录版保存后自动处理，隐私版只保存照片并等待登录。安装包不再包含 Tesseract、Leptonica 或本地 OCR 模型。
- 使用 iOS 的 `https://dianjie.org` 邮箱登录、Bearer 会话与云端 API。密码不落盘，凭证使用 Android Keystore AES-GCM 加密保存。
- 详情内继续思考、简洁 / 探索 / 整理 / 创意角色、失败重试、AI 回复沉淀为新想法与来源关系。
- 云端文字整理、图片理解、Stable Diffusion 1.5 生图、取消与幂等任务查询、相册保存、图片保存到想法、声音理解。
- 独立领域 / 主题 / 项目 / 表达性质标注、组合筛选、时间筛选、人工标注优先的批量重新整理；复用 iOS 的 LCC 快照显示名和关键词候选。
- 宇宙和脑图可拖动缩放、搜索并打开原文；使用相同的领域 / 主题分组。关联候选可调用云端 E5，确认关系单独保存，不把候选当成既成关系。
- 回忆反馈、保守的完全重复 / 空白候选清理、可恢复回收站与确认后的永久删除。
- 手动单条 / 全部上传：先传附件再提交同 iOS 的 format_version=1 快照，原文、引擎转写、人工修正、对话、图片分别保存。稳定快照按 revision 缓存，重试复用内容。尚无自动同步或云端恢复。
- 复用 iOS 的简体 / 繁体 / 英文 / 日文界面词条；新增词条暂时保留中文。

录音数据位于 App 私有目录。原音 fsync、同目录树原子 rename 后再事务提交 SQLite；UUID 幂等、启动时恢复文件与数据库提交间隙。数据库 v1→v9 迁移保留旧记录。永久删除写入墓碑，避免中断后旧音频被重新导入。语音转写与云端图片处理在后台执行。

## 与 iOS 的对齐边界

当前是对齐中的测试版，**不能称为功能与界面已经完全一致**：

| 项目 | 当前边界 |
| --- | --- |
| 主要导航与记录控件 | 已按 iOS 结构与黑色视觉实现；原生 Android 控件细节仍有平台差异 |
| 宇宙 | 已有领域 / 主题投影、旋转缩放与搜索；未移植 iOS 完整恒星系→行星→省→市的语义地理与地貌算法 |
| 脑图 | 当前显示领域→主题→Point，尚未覆盖完整地理层级、展开分页与布局算法 |
| 质量评估 | 可做领域人工评分与模型建议；尚未覆盖 iOS 各级成员 / 配对审阅、完整历史与接受 / 驳回流程 |
| 说话人与声音状态 | 人工标注与筛选已接入；尚未迁移独立声纹注册、自动声纹匹配与情绪候选管理 |
| 本地语音 | 当前只支持普通话，其他语言使用云端；不是 iOS 的 Whisper 多语言运行时，识别质量和标点有差异 |
| 图片 OCR | 仅使用点界云端视觉模型，需联网登录；长文超过服务输出上限时提示裁剪分图，不保存截断结果 |
| 网络模型 | 使用点界云端快速 / 增强路由；尚未迁移 iOS 的完整自定义供应商管理 |
| Google / Apple 登录 | 尚未移植 Android 对应授权流程，当前使用同一账户的邮箱密码登录 |
| 测试库与实验入口 | 尚未迁移 iOS 独立测试模式、批量造数和球面分布 Demo |
| 设备端生成式模型 | 按需求暂不适配 |

## 构建与验证

Android Studio 打开本目录，使用 JDK 17、Android SDK 35：

```sh
cd android
./gradlew assembleDebug
./gradlew connectedDebugAndroidTest
```

Gradle Wrapper 8.11.1 + AGP 8.9.3。Vosk / JNA 来自 Maven Central；Tesseract4Android 来自限定 group 的 JitPack 仓库。

本机已装 SDK 时可使用 SDK 脚本（依赖按固定版本与 SHA-256 获取）：

```sh
cd android
./scripts/build-local.sh
# 测试前准备官方语音模型到 .model-cache/vosk-model.zip
./scripts/test-local.sh
```

脚本默认使用 macOS 的 Android Studio JDK 和 `~/Library/Android/sdk`，可通过 `JAVA_HOME`、`ANDROID_HOME`、`ANDROID_PLATFORM`（android.jar 路径）与 `ANDROID_BUILD_TOOLS` 覆盖。版本号集中在 `version.properties`。

当前机器只有 API 37 平台和模拟器，因此此次 APK 使用 API 37 编译，安装包 minSdk=28、targetSdk=35。Gradle 构建通路尚未执行；相机并发已在模拟器的真实 Camera2 管线验证；Android 9 真机、不同厂商相机硬件和真实账户云端端到端仍待验收。

22 项设备端检查已通过，包括旧版数据库升级、录音与重启、按住松手保存、黑底录制状态截图、真实相机与音频并发、短录音 JPEG 保存、快速开关与后台恢复、预览和照片方向、字面搜索、转写候选保护、回收站与墓碑、快照稳定性、加密凭证、真正的中文离线语音识别，以及真正的本机 OCR。测试脚本必须使用专用测试设备，会授权麦克风、创建记录并清除测试设备的点界登录状态；本地 ASR 测试要求准备官方模型压缩包。

输出为 `app/build/local/pointverse-debug.apk`。固定调试签名保存在被 Git 忽略的 `.signing/debug.keystore`，应妥善备份以支持覆盖升级；正式发布另需发布签名。

## 0.2.1 相机修复

0.2.0 的 SDK 构建脚本把 `uses-sdk` 放在 `application` 后面，同时没有显式启用硬件加速。设备端实测预览视图 `isHardwareAccelerated=false`，TextureView 不会创建相机可用的 Surface，因此“同时拍摄”开关开启后无法启动预览。

0.2.1 将 SDK 声明放在 application 之前，并显式启用硬件加速；预览和 JPEG 尺寸从设备支持列表中选择，不再写死 1280×720。第一帧预览就绪时立即采样，结束时收齐进行中的 JPEG（最多等待 1.2 秒），再关闭相机。相机状态、采样和生命周期回调统一在主线程处理，支持快速开关、权限弹窗和后台返回后的恢复。

保留画面改为缩略图勾选，显示时读取 JPEG 的方向信息，原始文件保持不变。新增相机设备端检查验证“开相机时立即开始录音、不到 8 秒取得实际 JPEG、保存到同一条语音想法、系统返回和切后台后恢复”。不把相机开关状态当作拍摄成功依据。


## 0.2.2 图片理解与采样

采样与 iOS 对齐：每 1.2 秒一张，最多 12 张；结束时按 `i*(n-1)/(5-1)` 均匀选出最多 5 张供保留，短录音也会在预览就绪时立即取第一张。照片原件先保存，之后逐张提取本机文字，并在登录版调用 `/v1/ai/chat/completions`（与 iOS 相同的 pointverse-cloud / pointverse-cloud-enhanced 别名、1024 边长、JPEG 65 / 35、500 KB 上限和 256 token 输出）。

图片理解、OCR、人工说明分别保存。数据库升级保护已有文字；重新理解保留人工说明，并单独展示最新候选。图片内容进入继续思考、整理、搜索、关键词分类、关联分析与生图提示；分析变化清除旧向量，迟到的向量不能覆盖新版本。后台任务独立于详情页面，处理状态与错误可见；登录 / 模式变化恢复等待任务，进程重启恢复中断任务，失败后可重试。切换隐私模式或退出登录会阻止尚未发送的云端任务，原图与已完成 OCR 保留。

设备端回归覆盖真实多帧拍摄、保存后逐张真实 OCR、五页界面、录音与离线 ASR；照片处理测试覆盖模型请求格式、逐张队列、隐私 / 登录门控、网络失败重试、人工修改竞态、旧库升级、删除后的迟到结果和上下文 / 向量版本。云端测试使用替身响应；生产账号真实视觉效果与 Android 9 真机仍需验收。


## 0.2.3 应用内更新

「模型 → 检查更新」打开独立更新页，读取 `https://dianjie.org/downloads/android/releases.json` 中的 latest，以 versionCode 判断是否需要更新。首次使用此功能需先手动安装 0.2.3；之后发现新版时可直接下载并安装。

下载限制在本站 HTTPS 固定目录，拒绝重定向，支持取消、失败后重试和复用已校验的完整缓存。安装前校验声明大小、SHA-256、APK 实际包名 / 版本 / 最低系统版本，以及安装包证书与当前应用证书；不同签名或旧版本不能覆盖。临时下载不对外共享，失败或取消清理半包；完整文件通过仅可读的私有 ContentProvider 授权系统安装器读取。

首次安装在 Android 9 及以上需允许点界安装来自此来源的应用；从设置返回后继续校验并打开系统安装确认，权限未开启或用户取消安装时保留完整包供重试。系统负责最终安装确认，不提供静默安装。权限设置期间的版本信息随页面状态保存，完整包留在本机缓存；退出更新页会停止尚未完成的下载。

设备端更新测试使用相同签名的未来版本小 APK（只展示安装确认，不安装），覆盖版本目录、文件路径、包名、签名、完整下载、损坏缓存、截断 / 超长 / 重定向响应、取消清理、只读授权、无账户入口和 Android 原生安装器。发布后已在模拟器用旧版本读取网站、下载正式 0.2.3、走首次安装来源授权并完成系统覆盖安装；安装后的 APK 与网站 / 本地发布包 SHA-256 一致，42 条记录和 24 张图片的内容完全保留。47 项完整回归通过；Android 9 真机安装仍需验收。


## 0.2.4 移除本地图片识字

图片文字识别改用现有点界云端视觉路由（pointverse-cloud / pointverse-cloud-enhanced），以保留原语言、原词、阅读顺序和换行的专用提示提取文字。输出上限与现有网关的 512 token 限制一致；返回 length 时提示裁剪分图，不把截断文本标为成功。无文字返回明确的空结果。图片理解仍独立请求，识字失败可保留已完成的理解并只重试文字识别。

隐私模式及未登录时，自动处理和单图 / 独立文字提取均不发送图片。旧版本 OCR 文本保留至云端替换成功，人工说明不被覆盖，OCR 来源单独记录。数据库 v4→v5 将旧本机识字标记为待云端重识别，已有云端视觉结果不必重复请求。删除本地 Tesseract 引擎、四架构 OCR 原生库及随包中英文 traineddata；构建前清理依赖输出，防止旧库混入新版，并清理设备上旧 OCR 数据目录。离线语音转写保留。

测试覆盖云端 OCR 协议、隐私和登录门控、逐张队列、无文字 / 截断处理、部分失败与重试、旧本地结果升级、人工修改和删除竞态，并检查已安装 APK 中没有本地 OCR 引擎和模型。真实云端识字质量仍需登录生产账户验收。

0.2.4 最终 APK 为 14,374,650 字节（约 13.7 MiB），本地 ZIP 检查及设备端测试确认无 OCR 原生库 / traineddata；完整模拟器回归 49 项通过。

宇宙视觉在本版未重做。iOS 的 SwiftUI Canvas / GraphicsContext 无法原样用于原生 Java View，但其语义分区、坐标、层级、轨道、地表及镜头规则可以移植。Android 当前仍是按领域画球体的简化版，尚未迁移 iOS 完整的 SemanticGeographyEngine、CosmicHierarchy 和分层渲染；差异源自实现范围，而不是 Android 无法绘制这些效果。

## 0.2.9 想法页与音乐声音

- 修正接口误用：音乐/环境声调用 `/v1/ai/audio/classifications`，不再调用声纹/状态接口 `/audio/analysis`（该接口只接受 5.1–10 秒音频）。云端取前 30 秒，分类候选分数是相对分数。
- 对齐 iOS 音乐卡片：全长响度、节奏（前 5 分钟）、音高/音符/调性/序列（前 20 秒），音符试听、人声/歌词候选重转写、来源和失败提示。基础 DSP 无需模型下载。多乐器与复杂现场仅为估计，无曲库歌名识别。
- 分析结构化保存在原 analysis 字段，旧声纹 JSON 不当作音乐结果。声音语义加入标题、整理、对话和关联上下文；更新时清除旧文本向量，转写与原音不覆盖。
- 想法列表展示说话人和状态，支持二者组合筛选并清除筛选，筛选空态不再显示新用户提示。

详情页右上操作菜单补齐添加图片、声音理解、重新理解照片及显影快捷入口；单音不估计调性，云端仅最强候选进入语义上下文，避免把低分候选当作事实。

## 0.2.10 显影与预设滤镜

显影是一种风格化地重遇想法与回忆的体验。内置原貌、诗意、梦境、幽默、抽象、极简、复古提示词滤镜，影响云端文本模型的理解和表达。完整素材先由文本模型提炼，再提交当前图像生成器；长文本分段归纳，最终提示安全限制 600 码点。中间总结和提示词不展示，不强制展示文字或跳转到生图表单，作品完成后自动保存并揭晓。

数据库 v8 保存作品类型、来源版本与滤镜；文字也可以是独立作品的数据类型，其他媒介尚未实现。作品随回收站恢复，彻底删除时清理，同步快照携带记录。同一账户/素材/滤镜续查任务，过期后重建；400 参数错误与排队繁忙有明确提示。原始想法保持完整。

任务创建/续查遇到临时 502/503/504 时有限退避重试，创建复用同一幂等请求，防止重复生成；不会因续查短暂故障清除已提交任务。

本版验证：91 项设备端回归通过（Android API 37 模拟器）；真实云端以 898 字合成回忆完成梦境滤镜显影，得到 512×512 作品，验证原文完整、留在想法页、自动保存与揭晓。最低 API 28，Android 9 真机尚未验收。

## 0.2.11 宇宙交互

对照 iOS UniverseInteractionPolicy 迁移相机拟合、相对倍率动画、星球尺寸、6 秒交互暂停及后台不跳帧。远景拖动平移，星球表面拖动以投影半径换算旋转；点星球先靠近，只有正面单点才打开原文；双指手势不触发单击，缩放保持目标屏幕锚点，聚合按球面距离计算，旋转不改变分组。搜索转正并靠近目标，目录直达星球/主题或打开匹配想法，支持全景与缩放按钮。

脑图支持恒星系/行星/主题/Point 卡片展开收起、定位、查看原文。相机、球面方向及展开状态在原文往返、标签切换及 Activity 重建时保留；宇宙数据不再被想法页上次搜索误过滤。这里只迁移交互与相机；底层地理分区、行政边界与完整语义布局还未移植，因此不声称布局与 iOS 完全一致。

双指按稳定 pointer ID 跟踪跨度，直接换算相对倍率，不受系统额外最小跨度限制；指头增减会重建基线，剩余一指不会误触打开或造成地图跳变。

## 0.2.12 手动双向云端同步

“我的 → 云端同步”提供上传到云端、下载到本机、云端版本浏览。上传全部/单条原音、照片、转写候选、原文、对话、显影作品与 Android 分类状态；云端按内容保存不可变版本，已存在附件跳过上传。下载每条最新版本，也可逐版本同步或另存为新想法。

下载先校验版本与所有附件的 SHA-256/字节数，再事务写入完整记录。未修改的本机记录可更新，两端均修改时保留云端副本；重复同步不重复导入，本机回收站/墓碑不自动复活，主动另存副本可恢复。同步按账户记录版本基线；切换账户/隐私模式或暂停会停止后续操作，已完成记录保留。失败按条报告，可重试。临时 502/503/504 有限退避重试，附件预检查不可用时退回幂等上传。

iOS format_version=1 的原文、原音、图片、转写和文本对话可导入；额外原音保留并可播放，未知原始 payload 字段保留用于再次上传。只支持手动同步，不自动传播删除，也不自动上传新内容。数据库 v9 增加同步基线及来源记录，并清除旧版不完整快照缓存。

本版验收：132 项设备端回归通过；临时账户经生产接口完成上传、隔离资料库下载和界面下载，原音 SHA-256 一致且可解码播放，照片/人工修正转写/对话/显影作品均保留，重复下载跳过。测试账户、云端附件和模拟器测试记录已清理。最低 API 28，Android 9 真机尚未验收。

## 0.2.13 恒星与独立测试模式

恒星由固定 3dp 小点改为基于视距和所属想法数量的白/黄/橙亮核，最小半径 8dp，配独立柔光与标签；点选范围至少 24dp，初始全景同时纳入恒星与行星。

宇宙页“测试”或“我的 → 实验工具 → 进入独立测试模式”进入独立 test-points.db 与独立附件目录。顶部提供 +100、球面样本（复用 iOS 1024 条内置语料与坐标）、24 条回忆样本、清空和退出。演示坐标只在测试库使用，不冒充正式语义向量。测试库的增删改、图片草稿和生图任务与正式库分开，清空只触及测试媒体；数据不参与云端同步，模型与账户设置继续复用。无需下载模型或额外联网即可生成内置样本。

本版验收：140 项设备端检查通过，覆盖正式库保护、测试库清空、1024 条样本幂等载入、演示坐标、回忆样本、测试库禁止同步、模式进入/退出与草稿隔离，以及恒星亮核实际像素亮度。
