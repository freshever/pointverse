# 分层质量评估原型

更新：2026-10-19。已随 build 20 归档并成功上传 TestFlight，Apple 正在处理安装包。

## 入口与流程

宇宙页右上角「分层质量评估」（对话气泡勾选图标）→ 恒星系 → 行星 → 省 → 市 → Point。
保留的旧球面页「查看分区主题与成员」中也提供入口，不恢复旧 Tab。

每一级可选择「评估整个区域」，市级进入成员评估。支持：逐级浏览／指定层级平铺、名称或内容搜索、最少 Point 数量、含已评估／含未评估、内容数量或名称排序。评估状态检查当前节点及后代，以保留可继续进入的路径；行上标注的已／未评估仅指该节点自身。筛选范围限定为当前区域的下级。

层级复用地图的 `CosmicHierarchy`，恒星系／行星不另造分类。行星以完整持久化社区为分组单位，避免同一省被拆到不同星球。省沿用持久化社区，市改用 `SemanticSubtopicEngine` 对省内向量聚类，与镜头、方位无关；缺向量、少于4条或分离不足时不分市，直接展示 Point。尚无社区的内容归入「待分区」，不静默丢弃。默认名称参考具体主题与同级差异，人工命名优先。

恒星系／行星评估 ID 使用成员集合摘要，省市 ID 包含所属行星、社区及语义城市成员摘要，避免同名区域或临时数组下标串评分。语义市不复用旧方位桶ID。重新分组造成成员变化时，高层 ID 可能改变；旧快照仍保留，但跨版本全局检索／自动对照尚待实现。

1. 先看内容，选择主题集中／大体合理／明显混杂／暂时无法判断，可选人工 1–5 分并填写理由。
2. 逐条标记属于这里／也属于别处／应该移走／不确定。
3. 展开「显示算法证据」，对照原始余弦指标。
4. 对采样内最弱的最多 12 对内容，判断同一主题／不同主题但有关联／基本无关／不确定。
5. 可调用当前语言模型，每次明确评估下一批最多 6 条。
6. 记录接受／驳回／稍后处理，并保存本次评估快照。

**接受只是记录意见，不搬动 Point、不改省名、不改变聚类。** 归属调整需要后续实现人工约束与撤销机制。

## 三类证据不混算

- 人工质量分：1 分明显混杂，3 分部分合理，5 分主题集中且归属合理；可不评分。
- 算法：所选区域内原始余弦 P10、中位数、P90，区域外中位数与内外差值。不显示成正确率或概率。
- AI：共同主题、集中程度、偏离成员及理由、保持／改名／拆分／个别调整建议。实际模型标识与完整批次输入片段一同保存。

所有算法指标默认隐藏，允许先盲评。人工意见、算法指标与 AI 建议独立保存，不自动计算综合分。

## 算法与规模控制

使用当前 E5 模型、当前内容修订的有效向量；排除空、非有限、零范数与异常维度的向量，先 L2 归一化。向量维度取数据中多数维度，平票时取较小维度。

所选区域内／区域外各最多 128 条，按 Point ID 排序后等距抽样；不依赖相机和输入数组顺序。后台任务计算指标，最多 8,128 对区域内比较及 16,384 对内外比较。

区域外指整个当前数据库中所有不属于当前所选区域、且有有效向量的 Point（包括尚未分省的内容），不局限同一父区域。「值得复核」的条件是：该项与区域外样本的最大余弦，大于与区域内其他样本的中位数至少 0.05。该启发式只用于排查，不是移走依据。单成员、无区域外样本等情况明确显示样本不足。

关系复核展示采样内余弦最低的最多 12 对，因此是定向排查，**不能将其人工通过率当作随机样本准确率**。

回忆样本使用人工合成向量，页面明确警示不能据此评估 E5 准确度。

## AI 范围与隐私

复用当前语言模型选择与共享执行锁，支持已接入的本地／网络语言模型，实际输出模型信息不以配置名冒充。专用评估接口不复用聊天的 900／1200 字符上下文裁剪。

每批最多 6 条，每条最多 320 字符，保存成员 UUID、编号与实际片段。批次有明确范围与已评估计数；模型只评价本批，不声称理解整个省，不能汇总成完整省份结论。失败不推进批次，可再次尝试。

按钮前说明：网络模型会收到这些片段，点击执行表示同意；本地模型不上传。评分为按需调用，不后台自动发起，不自动回退到另一个服务。模型输出仍可能不准确，应由人复核。

## 存储

数据库迁移 v14 新增 `province_evaluations`，JSON 载荷包含：

- 评估 ID、时间、省 ID 与当时名称；
- 区域层级与完整名称路径；旧快照缺少这些字段仍可解码，默认按原省份评估理解；
- 全部当次成员原文、ID、可用时的向量内容修订；
- 人工质量分、分类评价、逐条及逐对意见、文字理由；
- 算法指标、采样数量、候选成员及最弱对；
- AI 每批输入／输出、实际模型、人工决策；
- 提示词／评估版本 `province-review-v1` 与地理版本。

每次保存新增快照，不覆盖历史。同一省页面可查看旧快照；当前尚无跨省全局历史或自动前后差异报告。改名不改变历史名称，后续内容变更不替换快照文本。

记录写入 AppContainer 当前数据库，正式／测试数据不共享。清除测试数据同步删除测试评估，保留正式评估。快照保留原文用于追溯，并不是只保存到全局设置。

## 验证

- 单元测试覆盖：归一化、省内／省外区分、单成员、非法向量、采样上限、输入顺序不变、评分与关系标注往返、独立数据库隔离、测试库清理不影响正式评估。
- iOS Debug 无签名编译验证。
- 待实机验证：大省滚动体验、各本地模型实际输出质量、网络失败重试及端到端人工使用流程。未替用户发送真实内容到网络模型。

## 后续

跨省历史与聚类前后对比；按人工意见计算独立评测集指标；AI 跨批总结与跨省候选；可撤销的人为归属约束。不要先让 AI 自动修图，再拿修图结果证明聚类正确。
