# 语义层级分类调整

2026-10-19，build20上传后工作区，尚未发布。

## 问题

原结构将单个 Point 的三维位置用于行星分组，再用持久化社区做省、球面方位桶做市，混合了三种不同的划分依据。同一社区可能跨行星；多个社区命中同一粗主题名，方位不同却内容相近的市也会重名。重名不等于 Point 重复，但会让层级看起来不像语义整理。

## 当前改动

1. **行星保全社区**：`communityUnits` 将已有社区当作不可拆分单元，再按单元中心分配行星；尚无社区的 Point 单独作为待分区单元。
2. **省不做破坏性重算**：仍沿用保存的社区ID，不移动坐标、不覆盖人工地名。名称不再只使用“软件工程”等粗标签，会参考具体关键词及同级区别。
3. **市按省内语义可选划分**：输入当前省的有效 E5 向量，不使用经纬度。少于4条、向量缺失／无效、近乎相同或分离不足时整省不分市。
4. **共用结果**：`EvaluationHierarchy` 生成市成员和名称，脑图／评估直接使用，宇宙球面使用预计算的同一组语义标签。不在拖动或旋转每帧执行聚类。
5. **避免错套旧地名**：新市ID使用成员集合摘要，不复用旧方位桶索引。旧人工地名未删除；省名继续沿用原key，语义市可通过地名编辑保存自己的名字。

## 子主题算法 v1

- 对向量归一化；用归一化平均中心估计离散度，平均 `1-cos` ≤ 0.008 则不拆分。
- 去除本省平均公共分量，减轻 E5 公共背景导致的普遍高相似度。
- 稳定ID顺序、最远优先种子，最多6组且不超过成员数的一半；新种子与已有种子的最大余弦须低于0.55。
- 8轮余弦中心迭代；不足2条的小组归入最近的实质组，不另造单点市。
- 平均组内中心相似度与最近组间中心相似度差须达到0.15，否则放弃划分。
- 所有成员恰好出现一次。阈值是启发式，不是经过标定的正确率，需要后续真人／AI评估。

默认名来自内容关键词和同级频率差异，不是自动调用网络模型理解后的结论。同名不触发自动合并；人工改成的相同名称也不会擅自覆盖。

## 边界

这是修正层级一致性与子主题划分，不是重新训练模型，也没有自动合并历史社区。若持久化省份本身混杂或碎片化，仍需评估后进行显式的社区重建／合并，不能只通过改名宣布分类正确。

旧星球演示及没有提供语义层级的保留渲染调用仍有原方位降级路径；当前默认宇宙球面已接入共享语义层级。新结构可能改变行星归属及评估范围ID，但不删除旧评分、原文或历史地理坐标。

测试覆盖相同向量不拆分、小样本／缺向量降级、不同主题可分、输入顺序确定性、每条恰好一次及完整社区单元。真实中文内容的分类准确度仍需用户评估，不以单元测试通过代替效果验证。
