# 账户、手动上传与网页展示

本期实现的是私人账户的手动上传闭环：网页注册 → iOS 邮箱登录 → 单选/多选想法上传 → Web 浏览文字、图片和原音。登录本身不上传本地资料。

## 使用

1. Mac 打开 `http://localhost:8090/account/` 注册邮箱账户。
2. iPhone 和 Mac 连接同一 Wi-Fi。iOS 模型页 → 登录点界 → 账户服务地址，输入 Mac 的局域网地址，例如当前开发机的 `http://192.168.3.4:8090`，连接后使用同一邮箱密码登录。局域网 IP 会变化，换网后应更新。
3. 进入账户页的「云端同步」，点选单条或多条，也可全选，然后上传。页面显示待上传、上传进度、已上传或失败原因。
4. 登录网页后点击「查看云端想法」，或访问 `http://localhost:8090/account/library.html`。点击刷新查看手机上传的内容，可搜索标题/摘要，筛选图片、录音、文字，打开详情查看原文和转写、浏览图片、播放原音。

服务地址设置在 Debug 与 Release 均可使用。公网服务必须 HTTPS；本地 HTTP 只允许私有 IP、localhost 或 `.local`。真机拒绝 localhost 连接地址，防止误连接到手机自己。Google / Apple 仍需申请并配置应用标识；邮箱登录独立可用。

## 上传范围

每条想法在一致的 SQLite 只读快照中收集：

- Point 元信息与标题、原文及对话消息，保留实际模型来源。
- 原始音频、图片、图片文字、引擎转写与用户修正、多转写候选。
- 已有标题派生记录、人工分面分类、确认关系与来源引用。

关系只上传引用，不因选择一个想法自动上传被引用想法的原文。任务队列、模型权重、Embedding、声纹向量等不在本期上传范围。回收站内容不能开始上传；本地删除不自动删除云端快照。

## 一致性与失败处理

- 附件先传输，通过 SHA-256 和长度校验后保存；全部附件到齐才提交并显示完整 Point。
- 相同账户内附件按内容哈希复用。上传失败后重试先检查已存附件，已完成文件无需重传。
- 完整 manifest 的 SHA-256 标识一个内容版本；同一版本重复提交幂等，不同内容即使修订号相同也分别保留。旧版本不会覆盖新版本的文件。
- 上传后重新读取本地快照，上传过程中继续修改的内容仍会显示待上传。
- 离开上传页会暂停；失败项保留选择，可再次上传。当前不是系统后台自动传输，进程被终止后需要重新选择未上传内容，不会宣称已完成。
- 上传期间不允许退出账户。账户服务、用户身份或会话变化不会把另一账户的上传状态沿用过来。
- 会话存于 Keychain，密码不持久化；会话过期和服务不可用分别显示错误。

## 云端与存储

PostgreSQL `cloud_assets` 保存附件归属，`cloud_point_versions` 保存不可变内容快照。附件保存在 Docker `cloud_data` 命名卷，API 容器以非 root 用户访问；普通容器重建保留数据。目录按服务端用户 UUID 隔离，不使用客户端路径或文件名作为服务端路径。

限制：单文件 128 MiB、每条最多 128 个附件、manifest 4 MiB；每账户附件合计 2 GiB、manifest 合计 128 MiB。超限明确失败。未提交 Point 的已上传文件不展示为完整想法，目前没有定时垃圾收集或用户配额管理页。

原生 `/v1/sync/*` 只接受 Bearer 会话，网页 `/web/sync/*` 只接受 HttpOnly Cookie。每次读取内容和文件都检查当前账户。网页不把访问 token 放进 URL 或本地存储。图片和音频按实际文件签名决定展示类型，其他内容按附件返回；播放器支持 Range 请求。

Web 默认展示每条 Point 最近上传的快照，保留的旧版本可在详情里切换。当前没有云端编辑、下载恢复到 iOS、自动双向冲突合并、云端删除和端到端加密；因此本期不作为全库备份恢复能力交付。

## 验证

- Go race 集成测试覆盖未登录拒绝、跨账户隔离、校验失败、附件未到齐、重复提交、相同修订不同内容保留、进程重建读回。
- Swift 测试覆盖邮箱接口错误、稳定快照、修改后 hash 改变、原文与对话保存、图片引用、回收站排除。
- 可选 Docker 实测：`POINTVERSE_SYNC_TEST_URL` 和 `POINTVERSE_SYNC_FIXTURES` 配置后运行 `CloudSyncLiveTests`，测试邮箱登录、文字/图片/原音上传、HEAD 复用、重复提交与逐字节下载校验。样本为合成测试资料。
- 完整 iOS 用真机目标编译；现有 llama 库缺少模拟器切片，账户和同步界面采用独立预览应用验证。

本轮结果：Go race 集成测试、6 项 Swift 单元测试、Docker 原件读回测试及完整 iOS 真机目标编译通过。签名的独立模拟器 UI 测试通过邮箱登录、单选上传、多选上传和重启恢复；Web 实测确认图片展示与 1 秒合成录音可播放。未安装到实体 iPhone，也未上传 TestFlight。
