# 只读层级脑图原型

更新：2026-10-19。build 20 上传后的工作区功能，尚未归档上传。

## 入口与交互

「宇宙」页顶部提供「宇宙／脑图」切换，不增加 Tab。

- 我的宇宙 → 恒星系 → 行星 → 省 → 市 → Point；待分区的内容可直接展开到 Point。
- 默认只展开根节点，显示恒星系。点节点右侧箭头展开／收起下级。
- 点节点主体选中，在底部查看名称、路径、记录数或内容摘要；Point 可「打开原文」。
- 拖空白平移，双指缩放，另提供放大／缩小、适合屏幕、收起全部。
- 所选节点可「定位」；宇宙页现有搜索选中 Point 后，脑图会自动展开祖先、翻到其所在分页并居中。
- 每个分支先显示最多 24 项，点击「再显示24项」增加；未展开内容不参与当前画布布局。
- 点击主体、展开箭头及加载更多后，当前焦点居中于实际绘图区，以1.2倍的可读比例展示附近内容，不为塞下全部子项而缩小。仅在视口连焦点卡片都容不下时适度缩小；周边超出画布可拖动查看。底部保留本次已加载子项的可滚动列表。「适合屏幕」仍是独立的全图总览操作。
- 聚焦与详情气泡独立：只有点击节点主体（或详情中的子项）才打开气泡；展开／收起、加载更多及搜索只聚焦，不自动弹出气泡。关闭气泡保持缩放和节点屏幕位置，不触发适合屏幕。

脑图自身只读，不改名、不拖动归属、不确认关系、不调用生成模型、不写数据库。打开原文后仍是现有详情页，其原有功能保持不变。

## 数据含义

复用分层评估的 `EvaluationHierarchy`，其恒星系／行星来自宇宙的 `CosmicHierarchy`，省来自持久化社区。行星以完整社区为分组单位，不再切碎一个省；市由 `SemanticSubtopicEngine` 对省内向量识别子主题，不再按方位强行分桶。复用已有宇宙布局，不额外执行一次星图力导向布局。

界面明确说明：这是推断的语义层级，**不是因果关系或经过验证的知识分类树**。内容少、向量不完整或子主题分离不足时，不造市，省直接展开到 Point。当前没有额外的支持、反驳、类比或候选相似度连线。

省市默认名参考具体关键词和同级差异，不再把所有技术社区统一叫“软件工程省”。人工省名优先。宇宙球面标签、脑图、评估共用语义城市成员与命名；旧方位市的人工名称仍保留在设置中，但不会套给成员不同的新语义市。

正式／测试模式自动读取当前页面的独立数据；展开、选择和镜头只存在页面状态，不存到全局用户设置。

## 实现与性能

- `ReadOnlyMindMapLayout` 为无数据库依赖的确定性树布局，固定列间距260、叶间距88；父节点位于可见子树纵向中心。
- 展开／收起以被操作节点为锚点补偿平移，避免无意义跳动。
- 说明栏、绘图区、底部面板独立占位，Canvas连线、节点位置与可视区裁剪使用同一尺寸，修复上方节点被盖住／裁掉的坐标不一致。面板高度变化只补偿视口中心位移，不重算缩放或重新适配全图。
- Canvas 绘制父子线，SwiftUI 节点卡片仅实例化可视区范围内的节点。
- 树结构在后台从共享层级构建；Point 按ID绑定，展开状态不依赖节点显示标题。
- 数据刷新保持可用的展开集合及镜头；切换回宇宙后再次进入脑图会重新初始化该脑图页面，镜头不跨模式持久化。

## 验证与边界

- 单元测试：仅遍历已展开节点；1000条成员分支的24项分页；确定性布局；叶节点不重叠及折叠结果。
- iOS Debug 无签名编译检查。未完成真机手势与视觉验收。
- 初版不含拖动节点整理、跨分支关系网、脑图专属筛选、导出或持久化自定义排版；质量评估仍从宇宙页现有入口进入。
