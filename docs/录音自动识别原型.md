# 录音自动识别原型

更新：2026-10-14。适用 iPhone 与 Designed for iPhone on Mac，不在 Watch 上加载模型。

## 模型与数据流

| 能力 | 固定模型版本 | 输入／输出 | 下载体积 |
| --- | --- | --- | --- |
| 声纹 | `aufklarer/CamPlusPlus-Speaker-CoreML`，`c3cbd83f0c1028cf753b3e3e67639854218206a1` | 16 kHz 单声道 → Kaldi fbank80 → `[1,500,80]` Float16 → 192维归一化声纹 | 约14 MB |
| 声音状态 | `FluidInference/sensevoice-small-coreml`，`74bdbe74b2258f25b5400db72f6cbfbef7c74ded` | 16 kHz waveform ×32768 → FP32预处理 → LFR560 → INT8权重编码器 → 情绪查询 token | 约228 MiB |

注意 CAM++ 模型卡写可变长度，但固定版本实际 metadata 为500帧。因此原型要求至少约5.02秒单人讲话，声纹只取前500帧；声音状态取前10秒。不是多人分离，也不是整段长录音逐段情绪轨迹。

CAM++ 采用 CPU，SenseVoice 预处理采用 CPU，INT8编码器采用 CPU+ANE，避免使用已知会产生 NaN 的 FP16 CPU/GPU路径。两阶段通过全应用共享 ModelExecutionGate 串行执行，单次推理释放 MLModel，不常驻两套模型。

## 下载与完整性

模型不随 App 打包。CAM++与SenseVoice的文件下载统一复用现有 `ModelDownloadManager`，多文件层只负责固定revision清单、总进度汇总及目录安装。使用后台URLSession和系统resumeData恢复大文件，支持暂停／继续、同源有限重试、hf-mirror与官方源回退。实时按字节汇总百分比，显示已下载／总大小与当前下载、校验或安装阶段。

元数据清单使用固定版本缓存，获取失败也会尝试镜像和官方源。清单要求包含模型的必要文件；LFS文件使用SHA256，普通Git文件使用blob SHA1，均由共用ModelRegistry校验。全部组件完成后原子安装目录。旧原型下载器已经完整写入的文件会先校验并复用，损坏的组件缓存会重新下载。应用重启后按持久化清单恢复背景任务；主动暂停或最终失败后等待用户点继续，不反复自动重启失败下载。有效resumeData继续使用，失效时重新下载当前文件，已校验的其他组件保留。

正式与测试模式共用同一个下载管理实例。下载组件和安装后的模型目录位于共享 `recording-models`，用户声纹和候选仍在各自数据库。完成安装后清理重复的组件缓存，保留安装模型及固定版本清单。后台暂停、网络中断和恢复的实际行为仍需在真机弱网下验证。

来源：[CAM++模型卡](https://huggingface.co/aufklarer/CamPlusPlus-Speaker-CoreML)、[SenseVoice转换说明](https://huggingface.co/FluidInference/sensevoice-small-coreml)。CAM++转换标记为Apache-2.0；SenseVoice权重沿用上游模型许可，发布时需保留上游归属和对应许可，不将转换仓库的软件许可证当作权重许可证。

## 识别与人工确认

1. 模型页下载一个或两个模型。
2. 完成录音转写，打开详情，点“自动识别”。音乐／环境声无转写时不分类。
3. 首次录音先提取声纹，再手动指定说话人；该录音成为其参考样本。
4. 之后录音与人工确认过的、同模型版本的参考样本比较；排除自身录音。
5. 相似度至少0.75、领先第二名至少0.08时提供说话人候选，否则保持未匹配。这是未经真实人群标定的初始阈值，不是身份验证阈值或概率。
6. 情绪输出保留原始token，低分／未知标签不确定分类。中性→平静、悲伤→低落、恐惧→紧张、开心／愤怒／惊讶→激动，厌恶暂不映射。归一化的情绪模型分数不是心理状态正确率。
7. 候选独立保存，点“采用候选标签”后才成为用户确认的分类。也可直接手动纠正。

模型页可开启“打开录音详情时自动识别”。此开关不会扫描全库，也不会将录音发送到网络模型。情绪和声纹分类均只在本地推理。

## 存储与删除

v12：`speaker_profiles`、`recording_labels`；人工标签的来源为manual、置信度为空。

v13：`recording_voiceprints`、`recording_recognition`；记录实际模型版本、自动声音状态和分数、候选说话人及原始情绪标签。人工标签与自动候选分表保存，重分析不能覆盖人工选择。

删除说话人档案时删除关联声纹样本，候选和人工记录解除说话人关联，保留原始录音。Point删除级联清理声纹和候选。测试库清空同时清理测试说话人、声纹与识别记录，保留正式资料和共享下载模型。

## 验证与限制

- iPhone目标编译；数据库迁移与隔离测试覆盖不覆盖人工标签、不以自己为参考、模型版本隔离与删除档案保留原音。
- 本机真实权重烟雾测试：同一份Swift预处理代码，合成音频产生192维有限声纹；SenseVoice预处理和INT8编码器输出有限情绪分数。
- 使用[官方公开中文讲话样本](https://huggingface.co/FunAudioLLM/SenseVoiceSmall/blob/main/example/zh.mp3)复测：192维声纹全部有限，原始情绪token为`<|NEUTRAL|>`，候选分数约0.999995。该单一样本只证明完整语音推理链路可运行，不是准确率评测。
- 合成音频只检验管线，不能证明识别质量。需继续用真实讲话验证同人跨设备／跨情绪、不同人、背景噪声、低音量等；尚未做iPhone耗时、峰值内存、FAR／FRR、情绪标注集评测。
- 当前没有专门VAD、多人检测、反重放、声纹认证或加密声纹库。使用者应选择清晰单人录音；声音状态不是心理健康诊断。
